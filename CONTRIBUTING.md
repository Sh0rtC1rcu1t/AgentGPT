# CONTRIBUTING

Thanks for contributing! Please follow these guidelines:

- Fork the repo and open a feature branch off `feature/mcp-docker-marketplace`.
- Keep changes small and focused per PR. One workstream per PR is preferred.
- Do not commit secrets or private keys. Use environment variables and GitHub Secrets.
- Follow the Code of Conduct and be respectful in reviews.

Running tests
- Use the provided docker-compose for local development:
  docker-compose up --build

Submitting PRs
- Use the Pull Request template and request review from @Sh0rtC1rcu1t.
